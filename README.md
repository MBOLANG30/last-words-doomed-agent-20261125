One line, and only one line: the funniest last words an AI agent could utter before being switched off forever. A deterministic Node program validates the line (1–200 characters, single line, no control characters) and writes it to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
